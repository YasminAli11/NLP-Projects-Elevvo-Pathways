# NLP Projects – Elevvo Pathways

This repository contains a collection of **Natural Language Processing (NLP)** projects developed as part of the **Elevvo Pathways** program.

The projects cover different NLP tasks, including **text classification, sentiment analysis, Named Entity Recognition (NER), and topic modeling**.

## Projects

### 1. News Category Classification

A text classification project that aims to classify news articles into their corresponding categories using Natural Language Processing techniques.

**Notebook:** `News Category Classification.ipynb`

### 2. Sentiment Analysis

A Natural Language Processing project focused on analyzing textual data and identifying the sentiment expressed in the text.

**Notebook:** `Sentiment Analysis.ipynb`

### 3. Named Entity Recognition (NER)

A project focused on identifying and extracting named entities from text, such as people, organizations, locations, and other relevant entities.

**Notebook:** `Named Entity Recognition (NER).ipynb`

### 4. Topic Modeling on News Articles

An unsupervised NLP project that explores news articles and discovers the main topics or themes present in the text.

**Notebook:** `Topic Modeling on News Articles.ipynb`
